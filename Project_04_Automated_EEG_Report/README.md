# Project 04 — Automated EEG Analysis Report

## 1. Overview

This project implements an automated EEG analysis and reporting workflow using Python and MNE-Python.

The workflow operates on preprocessed and ICA-cleaned EEG data generated by Project 03.

It demonstrates automated data quality assessment, channel-level amplitude analysis, spectral feature extraction, visualization, and HTML report generation.

## 2. Objectives

- Assess basic EEG data quality.
- Calculate channel-level amplitude statistics.
- Estimate power spectral density (PSD).
- Extract five frequency-band features.
- Calculate relative band-power measures.
- Generate EEG analysis visualizations.
- Automatically produce a self-contained HTML report.

## 3. Analysis Environment

## 4. Input Dataset

The input recording is the ICA-cleaned EEG dataset generated by Project 03.

| Property | Value |
|---|---:|
| EEG channels | 64 |
| Sampling rate | 160 Hz |
| Number of samples | 20,000 |
| Duration | Approximately 125 seconds |
| NaN count | 0 |
| Inf count | 0 |

## 5. Analysis Workflow

1. Load the ICA-cleaned EEG recording from Project 03.
2. Inspect data dimensions, sampling rate, NaN values, and Inf values.
3. Calculate channel-level amplitude statistics.
4. Estimate power spectral density using Welch's method.
5. Extract Delta, Theta, Alpha, Beta, and Gamma band features.
6. Calculate relative band power across the five selected frequency bands.
7. Generate channel-amplitude visualizations and relative band-power heatmaps.
8. Export CSV results and an automated HTML analysis report.

## 6. Frequency Band Definitions

| Band | Frequency Range |
|---|---|
| Delta | 1–4 Hz |
| Theta | 4–8 Hz |
| Alpha | 8–13 Hz |
| Beta | 13–30 Hz |
| Gamma | 30–45 Hz |

The absolute band-power features in this project represent the mean PSD within each selected frequency band, rather than the integrated spectral power.

Relative band power is calculated by normalizing the selected five band features against their combined value.

These definitions should be considered when interpreting the exported feature tables.

## 9. Limitations

- The input data has already undergone preprocessing and ICA-based artifact exploration.
- This project does not independently perform the complete raw-to-clean EEG preprocessing workflow.
- Amplitude thresholds are used for exploratory screening and should not be treated as standalone criteria for identifying bad channels.
- Frequency-band features alone cannot establish consciousness states or clinical conditions.
- Relative band power is normalized only across the five selected frequency bands.
- Results should be interpreted in the context of the experimental design, participant state, and other relevant evidence.

## 10. Data Availability

Before publishing this project, ensure that the EEG dataset is authorized for public use.

Raw recordings and potentially identifiable participant data should not be uploaded without appropriate permission.

## 11. Conclusion

This project demonstrates a reproducible workflow for automated EEG quality assessment, spectral feature extraction, visualization, and HTML report generation.

It provides a practical foundation for organizing and presenting EEG analysis results in a structured and repeatable format.
