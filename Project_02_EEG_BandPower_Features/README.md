# Project 02 - EEG Band Power Features

## Overview

This project extracts and visualizes spectral features from five
commonly used EEG frequency bands.

## Input Data

The project reads the filtered EEG recording generated by Project 01:

`../Project_01_EEG_Preprocessing_PSD/results/EEG_filtered_raw.fif`

## Frequency Bands

| Band | Frequency Range |
|---|---:|
| Delta | 1-4 Hz |
| Theta | 4-8 Hz |
| Alpha | 8-13 Hz |
| Beta | 13-30 Hz |
| Gamma | 30-45 Hz |

## Analysis Workflow

1. Load filtered EEG data.
2. Estimate power spectral density.
3. Extract features for five frequency bands.
4. Calculate absolute and relative band power.
5. Generate a band-power heatmap.
6. Export feature matrices and analysis parameters.

## Outputs

- `results/band_power_absolute.csv` - absolute mean PSD features.
- `results/band_power_relative.csv` - relative band power features.
- `results/params_project02.json` - analysis parameters.
- `figures/band_power_heatmap.png` - feature heatmap.

## Feature Definitions

Absolute band power in this project represents the mean PSD
within each selected frequency band, rather than the integral
of PSD across the band.

Relative band power is normalized across the five selected bands.
Therefore, the five relative values for each channel sum to 1
within floating-point precision.

## Notes

These features are exploratory signal descriptors. They should
not be interpreted as direct measures of mental state or as
validated BCI classification results.
